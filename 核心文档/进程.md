# 进程

## 过去

Arena 侧已经形成了“先生成稳定母本，再基于母本扩多角度”的图片资产路线，因此提出单独讨论 OpenRouter 生图 MCP，避免继续依赖网站手工下载再拖回工作区。

## 现在

第一版 `generate_image`、OpenRouter 客户端、能力校验、reference 转换、本地原子落盘与测试基线已经实现；现已新增用户级 MCP 安装/卸载脚本，并将仓库内自动生效的 `.vscode/mcp.json` 退役为开发模板，避免仓库克隆后直接重复注册。当前主线先收口“普通用户安装路径”和发布前仓库形态，再用真实可路由模型完成文生图与 reference 闭环。

## 未来

1. 下个执行回合补 README、许可证、平台限制、依赖、手动安装与更新说明，并按公开仓库形态整理发布面。
2. 完成真实文生图验证与 reference image 闭环验证，优先使用当时真实可路由且价格明确的模型。
3. 继续改进“模型可发现但不可路由”的错误提示与模型选择策略，避免把 endpoints 可发现误判为当前可生成。
