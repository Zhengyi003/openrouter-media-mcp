# 说明

## 对象定义

本目录是 OpenRouter 生图 MCP 的讨论、实现与交接工作区；当前已经确认以本目录作为第一版实现边界。

## 背景

当前痛点不是“缺一次图片生成”，而是生成链路仍停留在 OpenRouter 网站侧，导致生成、查看、筛选、复用 reference image 这几个动作没有在 VS Code 与 Copilot 的同一工作流内闭环。

## 目标

先判断并推进一个最小可用的 image generation MCP：让 Copilot 能在 VS Code 工作流中发起生图、直接看到结果，并把结果保存到工作区以供后续复用。

## 长期定位

当前只聚焦图片生成。音频生成、视频生成与更复杂的多模态能力只有在图片链路跑通后才进入评估范围。

## 职责边界

这里主要存放判断、约束、实现前提与交接信息；第一版 MCP 代码、生成图片与相关说明默认都以本目录为根组织。

## 阅读方式

先读进程.md，再读发现.md，最后回到现有的交接说明与参考链接。

## 工作区类型

这是一个独立代码项目根，已经初始化为单独 git 仓库，用于推进第一版 OpenRouter 生图 MCP。
